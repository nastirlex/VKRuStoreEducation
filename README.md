# Домашнее задание: Intent

Ветка `homework/intents` предназначена для отдельного учебного PR. **Не вливать в итоговый проект.**

## Что реализовано

- `MainActivity`: один Android `EditText` и кнопки «Открыть вторую Activity», «Позвонить другу», «Поделиться текстом».
- Явный `Intent` открывает `SecondActivity`, передаёт исходную строку через extra и показывает её в `TextView`.
- Неявный `ACTION_DIAL` открывает набор номера с URI `tel:`. Звонок автоматически не выполняется; разрешение `CALL_PHONE` не требуется.
- `ACTION_SEND`, `text/plain` и `EXTRA_TEXT` передаются в `Intent.createChooser` для системного окна отправки.
- Пустой текст и строки только из пробельных символов отклоняются с ошибкой у поля. Введённый непустой текст сохраняется без обрезки пробелов.
- Для телефона принимаются 3–15 цифр, необязательный начальный `+`, пробелы, скобки и дефисы. Разделители удаляются перед передачей номера; буквы, команды `*`/`#` и другие символы отклоняются. Это проверка формата, а не существования номера.
- Отсутствие обработчика внешнего Intent обрабатывается через `ActivityNotFoundException` и сообщение пользователю.
- Вторая Activity не экспортирована; отсутствие текста обрабатывается сообщением «Текст не передан».
- Экраны прокручиваются и учитывают системные панели и клавиатуру. EditText сохраняет содержимое при пересоздании Activity.

## Проверка

Проект использует исходные настройки репозитория: JDK 25, Android SDK 37, Gradle Wrapper.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

Для последней команды нужен запущенный эмулятор или подключённое устройство.

`InputValidatorTest` проверяет формат и границы длины номера. `IntentActivityTest` проверяет переход, текст extra, сохранение данных при пересоздании, ACTION_DIAL, содержимое ACTION_SEND в chooser, валидацию и отсутствие extra. Внешние Intent в тестах перехватываются, чтобы не открывать другие приложения.

### Ручные сценарии

1. Ввести многострочный текст, открыть вторую Activity и проверить точное отображение. Вернуться назад, повернуть устройство и проверить сохранение ввода.
2. Ввести `+7 (999) 123-45-67`, нажать «Позвонить другу»: должно открыться приложение набора номера с `+79991234567`. Не нажимать кнопку звонка.
3. Ввести текст, нажать «Поделиться текстом»: должно появиться системное меню отправки. Отменить или выбрать приложение и проверить текст.
4. Для всех трёх кнопок проверить пустую строку и пробелы. Для звонка проверить буквы, `12`, номер длиннее 15 цифр и `*100#`: должна появиться ошибка без перехода.
5. На устройстве без приложения набора номера проверить сообщение об отсутствии обработчика.
6. Проверить длинный текст и открытый экран с клавиатурой: кнопки должны быть доступны при прокрутке.

### Результат проверки в рабочей среде

`assembleDebug`, `testDebugUnitTest`, `lintDebug` и `assembleDebugAndroidTest` выполнены успешно. Все 3 unit-теста прошли (2 теста валидатора и исходный тест проекта). Lint не выявил ошибок; остались предупреждения о версиях зависимостей и ресурсах стартового проекта. Instrumented-тесты скомпилированы, но не запускались: тестовый эмулятор завершился при старте (код выхода 132), подключённых устройств нет.
