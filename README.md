# RuStore Education — список приложений и «Витрина»

Учебное приложение на Jetpack Compose с локальными данными, без сетевых запросов.

## Реализовано

- Акцентный тулбар с иконкой приложения слева и вертикальный `LazyColumn`.
- Общий `AppListItem`: иконка, название, краткое описание и категория.
- Готовая карточка из [практики](https://github.com/maltsevmicyou/VkEducation),
  а не заново придуманный экран. Источник и адаптации: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- «Витрина» отдельным последним блоком карточки, после разработчика:
  `HorizontalPager`, ровно **3 страницы × 3 приложения**, счётчик страниц.
- Тот же `AppListItem` переиспользован на каждой странице «Витрины».
- `NavHost` / `composable` / `rememberNavController`: `apps` → `apps/{appId}`.
  Нажатие на приложение в списке открывает соответствующую карточку;
  на любой элемент «Витрины» — возвращает существующий список через `popBackStack`,
  без накопления одинаковых экранов. Системная кнопка «Назад» также поддерживается.
- Состояния списка, карточки, описания и Pager сохраняются средствами Compose/Navigation.
- Локальные иконки и учебные иллюстрации, светлая и тёмная темы, системные отступы.

Установка приложений в учебном каталоге не выполняется: кнопка показывает Snackbar.
Кнопка «Поделиться» открывает системный выбор приложения, «Разработчик» показывает имя.

## Запуск и проверки

Откройте проект в Android Studio, дождитесь Gradle Sync и запустите `app`.
Требуются JDK 17+ (подходит JBR из Android Studio) и Android SDK 37.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

Второй вызов требует запущенный эмулятор или подключённое устройство (API 24+).
Unit-тесты проверяют данные и разбиение 9 приложений на 3 страницы.
Compose UI-тесты проверяют выбранную карточку, возврат из каждой страницы
«Витрины» и восстановление экрана/страницы после пересоздания Activity.

## Ручная проверка

1. Запустить приложение: тулбар и девять приложений в вертикальном списке.
2. Выбрать приложение: проверить его имя и иконку в карточке из практики.
3. Прокрутить карточку в самый низ: заголовок «Витрина», три строки, `1 / 3`.
4. Провести влево дважды: `2 / 3`, затем `3 / 3`; на каждой странице три приложения.
5. Нажать любое приложение «Витрины»: откроется список; повторить для остальных страниц.
6. Проверить «Назад», поворот устройства, тёмную тему и увеличенный шрифт.
